# SocialQ releases

Installers for [SocialQ](https://socialq.questera.ai), the Mac app that posts Instagram reels, photos and carousels from Google Drive on schedule.

Download the latest version from https://socialq.questera.ai or the [Releases](https://github.com/Questera-Marketing/socialq-releases/releases) page:

- `SocialQ-<version>-arm64.dmg`: Macs with Apple Silicon (M1 and later)
- `SocialQ-<version>.dmg`: Intel Macs

The app's source is private; this repo only holds signed, notarized installers.

Support: support@questera.ai
